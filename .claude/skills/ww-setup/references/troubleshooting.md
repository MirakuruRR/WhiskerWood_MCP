# Известные отказы

## setup

**`ProfileBusyError`, «каталог занят»**
Профиль держит запущенный MCP-сервер — Windows не даёт подменить каталог. Остановить
сервер (в Claude Code `/mcp` → перезапуск `whiskerwood`) и повторить `bun run setup
--force`. Действующий профиль не пострадал, индекс уже собран.

**«Дампы старше пака»**
Игра обновилась, дампы от прошлой версии. Собирать из них нельзя: `.usmap` со старым
layout ломает разбор молча — таблицы отдают ноль строк без единой ошибки. Переснять
(фаза 5). Флаг `--allow-stale-dumps` существует, но применять его без явной просьбы
человека не надо.

**«не удалось собрать сайдкар WwParse (dotnet build)»**
Нет .NET SDK 10 либо стоит только Runtime. Проверить `dotnet --list-sdks`: нужна строка,
начинающаяся с `10.`. Первая сборка тянет CUE4Parse из nuget — нужна сеть.

**«не найден python»**
`wwpak.py` вынимает `AssetRegistry.bin` из пака. Поставить Python 3 и добавить в PATH.

**Приёмочные проверки не прошли**
`setup` не публикует профиль и оставляет черновик в `dist/games/.staging-*`. Это не
проблема установки, а расхождение индекса с ожиданиями — версия игры могла заметно
измениться. Показать человеку, какая именно проверка упала.

## dumps:pull

**«AutoDump ничего не оставил»**
Мод не был включён или игра не дошла до нужной точки. Проверить `AutoDump : 1` в
`mods.txt` и что человек заходил в сохранение.

**«нет строки ALL DONE captured_at=...»**
Дамп не досняли: вышли из игры раньше, чем он закончился. Нужно ~60 секунд внутри
сохранения. Есть горячая клавиша `Ctrl+Alt+F9`.

**`captured_at=main_menu` вместо `in_level`**
Дамп снят в главном меню. Соберётся, но блюпринтовые классы UI в него не попадут.
Переснять из сохранения.

## bridge:deploy

**Игра запущена**
Скрипт пересоздаёт каталоги в `ue4ss/Mods`. Сначала закрыть игру:
`tasklist | grep -i whiskerwood` должен быть пустым.

**`(copy)` вместо `(junction)`**
Нет прав на символические ссылки. Работать будет, но правки в репозитории не подхватятся
игрой без повторного `bridge:deploy`. Лечится включением режима разработчика Windows или
запуском от администратора.

**`lib/ не найден`**
Ни в `<modsRepo>/lib`, ни в `data/lib` — проверить, что репозиторий склонирован целиком.

## Мост и живые инструменты

**`bridge_not_installed`**
Мост ни разу не стартовал: `bun run bridge:deploy`, затем запустить игру.

**`game_not_running`, heartbeat устарел**
Игра закрыта или подвисла. Если человек уверен, что игра открыта — проверить, что
`WWBridge : 1` в `mods.txt` и что в `UE4SS.log` нет ошибок загрузки мода.

**Игра падает на `ww_game_eval`**
Нативный access violation `pcall` не ловит. Проверять гипотезы по одной, а не пачкой;
разбирать падение через `ww_crash_report`.

## Конфигурация

**«Конфигурация не найдена»**
Нет `wwmcp.config.json`. Скопировать из `wwmcp.config.example.json`.

**«каталог не существует» на gameDir/exePath/pakPath**
Неверный путь до игры. `doctor` показывает, что нашёл через Steam — сверить с конфигом.

**`UE4SS.log` отсутствует**
Это предупреждение, а не ошибка: игра ещё не запускалась с UE4SS. Установку не блокирует,
но версия UE4SS не определится.
