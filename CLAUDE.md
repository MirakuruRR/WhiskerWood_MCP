Это репозиторий MCP-сервера для моддинга игры Whiskerwood (UE 5.6) под UE4SS.
Устройство — `docs/ARCHITECTURE.md`, инструменты — `docs/TOOLS.md`.

Правила для кода:
- не оставлять комментарии, только если очень надо в неочевидном месте и буквально несколько слов
- не пишем тесты
- проверка перед сдачей: `bun run typecheck` и `bun run doctor`

Знание об игре живёт в памяти сервера, а не в этом файле: до разведки — `ww_memory_search`
и `ww_lua_api`, после работы — `ww_memory_add`. Перечни инструментов и факты про отдельные
моды сюда не дублируем.

Общая база знаний (`data/memory-seed.jsonl`) правится не руками, а через
`bun run memory:export`. Личные пути вычищает санитайзер экспорта — см. `docs/MEMORY.md`.
