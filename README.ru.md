# Whiskerwood MCP

MCP-сервер, который делает из ИИ-ассистента толкового моддера Whiskerwood.

Whiskerwood — игра на Unreal Engine 5.6, моды к ней пишутся на Lua под
[UE4SS](https://github.com/UE4SS-RE/RE-UE4SS). Писать их вручную — значит угадывать имена
из рефлексии, пути хуков и поведение движка, а неверная догадка проваливается **молча**:
хук не встаёт, мод грузится, и ничего не происходит. Этот сервер убирает угадывание. Он
собирает локальный индекс рефлексии, таблиц данных и локализации игры и отдаёт 30
инструментов, которые отвечают на вопросы «что это за класс», «какой точный hook_path»,
«что написано по этому ключу» — плюс живой мост в запущенную игру: выполнить Lua, снять
дерево UI, сделать скриншот, разобрать краш.

Всё работает локально. Никаких сетевых вызовов в рантайме и никаких данных игры в этом
репозитории: индекс собирается из **вашей** копии.

## Требования

| | |
|---|---|
| ОС | Windows (игра, UE4SS и весь инструментарий — только под Windows) |
| Игра | Whiskerwood — Steam AppID 2489330 |
| [Bun](https://bun.sh) | 1.3+ — на нём работают сервер и скрипты сборки |
| [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) | 3.0.1, распакованный в `Whiskerwood/Binaries/Win64` |
| Python 3 | вынимает `AssetRegistry.bin` из пака игры |
| [.NET SDK 10](https://dotnet.microsoft.com/download) | собирает сайдкар на CUE4Parse, читающий таблицы данных |
| MCP-клиент | [Claude Code](https://claude.com/claude-code) или любой клиент с MCP поверх stdio |

## Быстрый старт

```bash
git clone https://github.com/MirakuruRR/WhiskerWood_MCP
cd WhiskerWood_MCP
bun install
cp wwmcp.config.example.json wwmcp.config.json   # поправьте пути, если автодетект промахнулся
bun run doctor                                   # скажет, чего именно не хватает
```

`doctor` проверяет тулчейн, находит игру через Steam, сверяет UE4SS, мост, дампы и индекс
и печатает следующую команду для всего, что ещё не готово.

Работаете в Claude Code? После клонирования просто запустите **`/ww-setup`** — скилл
проведёт по всей установке, включая шаги, которые скрипт сделать не может (поставить
UE4SS, снять дампы изнутри сохранения, перезапустить клиент). Ручной путь описан в
[docs/SETUP.md](docs/SETUP.md).

## Что внутри

- **[30 инструментов](docs/TOOLS.md)** — поиск по рефлексии, проверенные пути хуков,
  таблицы баланса, локализация, извлечение ассетов, каркас и валидация мода, горячая
  загрузка в запущенную игру, разбор крашей, скриншоты, дерево UI.
- **Общая база знаний** — 396 выверенных записей о том, что в этой игре действительно
  работает: какие идиомы движка здесь ломаются, какие подсистемы — тупик, почему выбран
  именно такой хук. Едет вместе с репозиторием и вливается в вашу память, не затирая
  собственные записи. Подробнее — [docs/MEMORY.md](docs/MEMORY.md).
- **Lua-библиотека рантайма** (`data/lib/ww/`), которая переживает оба режима загрузки
  UE4SS, кеширует дорогой поиск объектов и не даёт хукам копиться при dev-перезагрузках.

## Где лежат моды

Этот репозиторий — *инструмент*. Моды живут в своём репозитории по соседству:

```
<где угодно>/
  WhiskerWood_MCP/     этот репозиторий
  WhiskerWood_Mods/    ваши моды — можно начать с шаблона
```

[WhiskerWood_Mods](https://github.com/MirakuruRR/WhiskerWood_Mods) — одновременно рабочий
пример и готовый шаблон: семь опубликованных модов, правила работы для ассистента и
раскладка релизной сборки. В конфиге укажите `modsRepo` туда, где держите свои — пустой
каталог тоже годится, библиотека рантайма приезжает из этого репозитория.

## Как поделиться знанием

Если вы выяснили про игру то, что нельзя вывести из кода — подсистема не работает, идиома
ломается, хук пришлось выбрать именно так, — выгрузите это и пришлите сюда:

```bash
bun run memory:export --local-only
```

Команда пишет только ваши записи и заменяет личные пути плейсхолдерами. Приложите файл к
пулл-реквесту — и на следующем `git pull` знание окажется у всех.
