# Whiskerwood MCP

MCP-сервер для создания Lua-модов к Whiskerwood (Unreal Engine 5.8) и их внедрения в игру
через [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS).

Он даёт ИИ-ассистенту всё, чтобы писать рабочие моды, а не угадывать: локальный индекс
рефлексии, таблиц данных и локализации игры, проверенные пути хуков, каркас и валидацию
мода и живой мост в запущенную игру — горячая загрузка, выполнение Lua, дерево UI,
скриншоты и разбор крашей. Список инструментов — в [docs/TOOLS.md](docs/TOOLS.md).

Всё работает локально. Данных игры в этом репозитории нет: индекс собирается из **вашей**
копии.

## Быстрый старт

Склонируйте репозиторий в любую папку:

```bash
git clone https://github.com/MirakuruRR/WhiskerWood_MCP
```

Этот репозиторий — *инструмент*, моды живут рядом с ним. Папка для модов создастся сама
при первом запуске:

```
<где угодно>/
  WhiskerWood_MCP/     этот репозиторий
  WhiskerWood_Mods/    ваши моды
```

Откройте `WhiskerWood_MCP` в любой АИ-среде и запустите скилл **`/ww-setup`**. Он проведёт
по всей установке: проверит тулчейн, найдёт игру, поставит UE4SS и мост, подключит
MCP-сервер, снимет дампы изнутри сохранения и соберёт индекс. Запускайте его снова, если
`bun run doctor` сообщает о проблеме.

Ручной путь описан в [docs/SETUP.md](docs/SETUP.md).
